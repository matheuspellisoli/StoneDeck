# Roadmap do StoneDeck

Acompanhe os próximos passos do desenvolvimento do StoneDeck. Nosso foco é tornar a criação de apresentações ainda mais flexível e poderosa.

## 🚀 Próximas Melhorias (Em Breve)

### 📐 Sistema de Layout Refinado
- **Margens e Padding**: Implementar um controle mais granular de margens e preenchimentos por slide e por slot.
- **Espaçamento Inteligente**: Ajustes automáticos baseados na densidade do conteúdo para evitar sobreposições em casos extremos.

### 🎨 Expansão de Temas
- **Novos Temas Padrões**: Adição de uma galeria de temas canônicos (Dark, Professional, Creative, Academic).
- **Personalização de Temas**: Simplificação do arquivo `theme.yaml` para permitir customizações rápidas de cores e bordas globais.

### 🔠 Tipografia e Elementos Visuais
- **Google Fonts**: Integração nativa para permitir o uso de qualquer fonte da biblioteca Google Fonts.
- **Biblioteca de Ícones**: Suporte integrado para bibliotecas populares (ex: Lucide, FontAwesome) via sintaxe simples no Markdown.
- **Suporte a Webfonts**: Melhorias no plugin HTML para carregar fontes remotas de forma eficiente.

---

## 🛠️ Desejado (Longo Prazo)
- Transições de slides no plugin HTML.
- Componentes interativos (gráficos leves).
- Plugin de exportação para formatos editáveis (ex: PPTX).
