# StoneDeck Roadmap

Follow the next steps in StoneDeck's development. Our focus is on making presentation creation even more flexible and powerful.

## 🚀 Upcoming Improvements (Soon)

### 📐 Refined Layout System
- **Margins and Padding**: Implement more granular control of margins and padding per slide and per slot.
- **Smart Spacing**: Automatic adjustments based on content density to avoid overlaps in extreme cases.

### 🎨 Theme Expansion
- **More Default Themes**: Addition of a library of canonical themes (Dark, Professional, Creative, Academic).
- **Theme Customization**: Simplification of the `theme.yaml` file to allow quick customizations of global colors and borders.

### 🔠 Typography and Visual Elements
- **Google Fonts**: Native integration to use any font from the Google Fonts library.
- **Icon Library**: Integrated support for popular libraries (e.g., Lucide, FontAwesome) via simple Markdown syntax.
- **Webfonts Support**: Improvements in the HTML plugin to load remote fonts efficiently.

---

## 🛠️ Future Goals (Long Term)
- Slide transitions in the HTML plugin.
- Interactive components (lightweight charts).
- Export plugin for editable formats (e.g., PPTX).
