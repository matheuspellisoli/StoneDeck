# Roadmap de StoneDeck

Sigue los próximos pasos del desarrollo de StoneDeck. Nuestro enfoque es hacer que la creación de presentaciones sea aún más flexible y potente.

## 🚀 Próximas Mejoras (Pronto)

### 📐 Sistema de Diseño Refinado
- **Márgenes y Relleno (Padding)**: Implementar un control más granular de márgenes y rellenos por diapositiva y por slot.
- **Espaciado Inteligente**: Ajustes automáticos basados en la densidad del contenido para evitar superposiciones en casos extremos.

### 🎨 Expansión de Temas
- **Más Temas Predeterminados**: Adición de una biblioteca de temas canónicos (Dark, Professional, Creative, Academic).
- **Personalización de Temas**: Simplificación del archivo `theme.yaml` para permitir personalizações rápidas de colores y bordes globales.

### 🔠 Tipografía y Elementos Visuales
- **Google Fonts**: Integración nativa para permitir el uso de cualquier fuente de la biblioteca de Google Fonts.
- **Biblioteca de Iconos**: Soporte integrado para bibliotecas populares (p. ej., Lucide, FontAwesome) mediante una sintaxis sencilla en Markdown.
- **Soporte de Webfonts**: Mejoras en el complemento HTML para cargar fuentes remotas de manera eficiente.

---

## 🛠️ Objetivos Futuros (Largo Plazo)
- Transiciones de diapositivas en el complemento HTML.
- Componentes interactivos (gráficos ligeros).
- Complemento de exportación para formatos editables (p. ej., PPTX).
